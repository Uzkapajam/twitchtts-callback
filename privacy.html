UzkaChat Privacy Policy

Last updated: May 8, 2026

Information the app uses

UzkaChat uses Twitch sign-in to display and manage Twitch chat. When you sign in with Twitch, the app may receive and use:

  • Twitch access token
  • Twitch user ID
  • Twitch login and display name
  • Twitch profile image URL
  • Twitch permission scopes and token expiry information
  • Twitch chat messages, events, badges, emotes, and viewer count

The app may also use Twitch API features for sending chat messages, moderation actions, VIP commands, and changing the stream title if the user has granted the required Twitch permissions.

How information is used

Information is used only to provide app functionality:

  • to connect to a Twitch account
  • to read Twitch chat
  • to send chat messages
  • to display Twitch profile images, badges, emotes, and chat events
  • to perform moderation actions when the user has the required Twitch permissions
  • to change the stream title when requested by the user
  • to store app settings on the device

Data storage

UzkaChat does not use its own server to store user data.

Twitch session data and app settings are stored locally on the user's device. Chat messages are used for app functionality and are not uploaded to a separate UzkaChat server.

The user can log out of Twitch inside the app. Logging out removes the stored Twitch session from the app's local storage.

Data sharing

UzkaChat does not sell user data and does not share user data for advertising purposes.

The app communicates with Twitch services to provide chat and Twitch account features. Some images, such as emotes and badges, may be loaded from Twitch or Twitch chat related image services.

Ads and analytics

UzkaChat does not show ads and does not use third-party advertising SDKs.

UzkaChat does not use third-party analytics SDKs to track user behavior.

Permissions

The app may use the following Android permissions:

  • Internet: to connect to Twitch chat and Twitch API
  • Notifications: to show the background activity notification
  • Foreground service: to keep the chat connection active in the background
  • Wake lock: to help keep the chat connection active while the app runs in the background

Children's privacy

UzkaChat is not intended for children. Use of Twitch is governed by Twitch's own terms and age requirements.

Changes to this policy

This privacy policy may be updated if new features are added or if the way data is handled changes.

Contact

If you have questions about this privacy policy, contact the app developer using the contact information listed on Google Play.
