UzkaSpeak privātuma politika

Pēdējoreiz atjaunota: 2026-05-10

Šī privātuma politika apraksta, kā lietotne UzkaSpeak apstrādā informāciju, izmantojot Twitch pieslēgšanos un teksta pārvēršanu balsī.

1. Kādu informāciju lietotne izmanto

Lietotne var izmantot šādu informāciju:

  • Twitch pieslēgšanās informāciju, piemēram, piekļuves tokenu un Twitch lietotājvārdu.
  • Twitch čata ziņas, kuras tiek nolasītas lietotnes darbības laikā.
  • Azure Speech API atslēgu un reģionu, ja lietotājs izvēlas izmantot Azure balsi.
  • Lietotnes iestatījumus, piemēram, izvēlēto balss dzini un lasīšanas komandu.

2. Kur dati tiek glabāti

Lietotnes iestatījumi, Twitch sesijas dati un Azure iestatījumi tiek glabāti lokāli lietotāja ierīcē. Lietotne neizmanto savu atsevišķu serveri lietotāja datu uzkrāšanai.

3. Kā dati tiek izmantoti

  • Lai lietotājs varētu pieslēgties savam Twitch kontam.
  • Lai lietotne varētu piekļūt Twitch čatam un nolasīt ziņas balsī.
  • Lai saglabātu izvēlētos lietotnes iestatījumus starp lietotnes palaišanas reizēm.

4. Datu nodošana trešajām pusēm

Lietotne pati nepārdod un neizplata lietotāja personas datus trešajām pusēm. Tomēr lietotne izmanto trešo pušu pakalpojumus:

  • Twitch lietotāja autorizācijai un čata piekļuvei.
  • Microsoft Azure Speech, ja lietotājs izvēlas Azure balss dzini.
  • Google Text-to-Speech, ja lietotājs izvēlas Google balss dzini.

5. Bērnu privātums

Lietotne nav īpaši paredzēta bērniem, kas jaunāki par 13 gadiem, un apzināti nevāc personas datus no bērniem.

6. Drošība

Lietotājs ir atbildīgs par savas ierīces drošību. Lietotnē saglabātie dati tiek turēti lokāli ierīcē, un lietotājam ieteicams neizplatīt savus piekļuves datus vai API atslēgas.

7. Jūsu izvēles

Lietotājs var jebkurā laikā:

  • izrakstīties no Twitch konta lietotnē,
  • mainīt vai izdzēst Azure iestatījumus,
  • izdzēst lietotnes datus ierīces iestatījumos.
